# NASA Milling Machine Dataset

## Overview
This folder contains the NASA Milling Machine dataset
used for research and experimentation in predictive maintenance.

## Dataset File
- `mill.mat` - MATLAB data file containing milling machine experimental data.

## File Format
MATLAB (.mat)

## Purpose
The dataset can be used for machine condition monitoring,
data analysis, and predictive maintenance research.

## Source
NASA Prognostics Data Repository.
